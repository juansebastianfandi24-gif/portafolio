# Placeholder para Imágenes de Proyectos

Coloca aquí las imágenes de tus proyectos.

## 📸 Recomendaciones

- **Formato**: JPG, PNG o WebP
- **Dimensiones**: 800x600px o 16:9 ratio
- **Tamaño**: < 500KB por imagen
- **Nombres**: usa nombres descriptivos (ej: `proyecto-ecommerce.jpg`)

## 🎨 Cómo agregar imágenes

1. Coloca tus imágenes en `/public/images/`
2. Actualiza las rutas en `src/data/projectsData.ts`
3. Next.js optimizará automáticamente las imágenes
